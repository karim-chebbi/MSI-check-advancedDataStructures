Graph Implementation in JavaScript

This project demonstrates a basic Graph data structure using an adjacency list in JavaScript.

✨ Features

Add and remove edges

Check if an edge exists

Print the graph

Traverse the graph using:

DFS (Depth-First Search)

BFS (Breadth-First Search)

Supports directed and undirected graphs

🧪 Example

The graph is tested with at least 3 vertices and both DFS and BFS traversals starting from one vertex.

🚀 How to Run

Clone the repository

Open the file in your code editor

Run with Node.js:

node index.js

🛠 Tech Stack

JavaScript (ES6)

Node.js
